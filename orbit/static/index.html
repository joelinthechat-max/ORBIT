Model management

No weights are bundled. You may explicitly start one user-supplied llama.cpp server at a time with CPU-only arguments. GGUF architecture/template and a matching vision projector must be selected by the user; a generic GGUF is not necessarily vision-capable.

Browser automation

Browser automation is optional and off by default. It uses a dedicated profile/download folder under DATA/browser, never attaches to the existing user/debugging browser, and does not submit forms without explicit approval. Webpage text and links are untrusted. Install the pinned browser only by running the opt-in setup script; host OS libraries/policies still apply.
